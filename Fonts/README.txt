VT323-Regular.ttf is an unmodified third-party font, distributed under its
own OFL license rather than the project's general source/art restrictions.
RPG Maker VX Ace loads this project's Fonts folder when starting Game.exe;
testers do not need to install the font into Windows.

The prototype uses it for the phone home and saved Messages screens only.
