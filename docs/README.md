# Wonder Christmas Fiesta — Documentation

Thư mục tài liệu được chia thành các nhóm sau:

- `tai-lieu-game/`: nguồn tài liệu thiết kế và sản xuất đang được duy trì. Các tài liệu route, map, system, asset và vấn đề production đều nằm trong cây này.
- `kich ban/`: tài liệu kịch bản nguồn để đối chiếu; không xem là bản triển khai runtime.
- `Mapshots/`, `Screenshots/`: ảnh tham khảo map và ảnh kiểm thử.
- Các file Markdown ở cấp `docs/`: báo cáo hoặc bảng kiểm chuyên biệt có phạm vi độc lập.

Không tạo lại `routes/`, `production/`, `systems/` hoặc `archive/` trực tiếp dưới `docs/`. Dùng các đường dẫn tương ứng trong `docs/tai-lieu-game/` để tránh tồn tại hai bản tài liệu cùng chức năng.
