# WCF 0.1.0-test.2 — Cho phép mở bản tester trong RPG Maker

Bản cập nhật ngày 17/11/2026 chỉ sửa updater và cách đóng gói. Dữ liệu game giữ nguyên so với `0.1.0-test.1`.

- Bỏ hoàn toàn chốt chặn thư mục dự án: có `Game.rvproj2`, `.git` hoặc script xuất rời đều không bị từ chối vì các dấu hiệu này.
- Thêm `Game.rvproj2` vào bản game đầy đủ, gói cập nhật và gói bootstrap để tester có thể mở game bằng RPG Maker VX Ace.
- Không yêu cầu Game mới riêng cho thay đổi này. Save và bộ sưu tập tiếp tục được giữ.

## Cập nhật từ updater cũ

Updater `0.1.0-test.1` còn chốt chặn cũ và chưa nhận dạng `Game.rvproj2` trong gói cập nhật. **Thay bootstrap mới một lần**:

1. Đóng game và RPG Maker.
2. Tải **wcf-updater-bootstrap.zip** của bản này, giải nén đè vào thư mục có `Game.exe`.
3. Chạy `GameUpdate.bat` để cập nhật.

Tải lần đầu: dùng **wcf-game-0.1.0-test.2.zip**, giải nén vào thư mục riêng. Có thể mở `Game.rvproj2` bằng RPG Maker VX Ace hoặc chạy `Game.exe`. Máy chơi game vẫn cần VX Ace RTP.

Theo yêu cầu tác giả, **không chạy lại bộ test hoặc thử cập nhật** cho thay đổi này; tác giả sẽ tự test. Những lỗi game đã ghi trong [bản trước](https://github.com/Vuongtiger98/WCF/releases/tag/v0.1.0-test.1) vẫn còn, gồm cửa ra Map063 và NPC E005 ở Map019.
