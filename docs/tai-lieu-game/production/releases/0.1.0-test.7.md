## Cập nhật

Mở game để nhận bản mới, hoặc đóng game rồi chạy **GameUpdate.bat**. Người tải lần đầu dùng **wcf-game-0.1.0-test.7.zip**; máy cần RTP RPG Maker VX Ace. Bản game có `Game.rvproj2` để tester mở bằng RPG Maker.

Bản này đánh dấu **cần Game mới** để kiểm tra Riu có sẵn, hướng dẫn đầu game và các điều kiện nhận thẻ. Updater vẫn giữ save, bộ sưu tập và thiết lập hiện có; không xóa tiến trình cũ. Các save trước bản này không được chuyển đổi điều kiện mở thẻ tự động.

Nếu vẫn dùng updater test.1, giải nén **wcf-updater-bootstrap.zip** mới một lần rồi chạy BAT.

Gói **wcf-qa-scroll-fix-2026-11-19.zip** được đính kèm lại cho tester chưa cài bản vá cuộn web app. Nội dung web app không thay đổi trong lần phát hành này; updater game không tự cài web app. Chép đè bản vá vào đúng folder cũ, giữ tên/vị trí `index.html` và dữ liệu trình duyệt để giữ tiến độ test.
