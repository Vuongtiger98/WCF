## Code chưa xác định được tác giả cá nhân

`Stairs Movement`, `Move the Menu`, `Cutscene Group Chat`, `Custom Menu`, `Transform Form Selection`, `Catto Petting Minigame`, `Multi Switch Condition Helper`, `Atlantis Shrimp Fishing`, `Atlantis Mirror Maze Chase`, `WCF Snowball Rhythm`, `WCF Storage Memory Transition`, `WCF Test Hub` có code riêng cho project nhưng không có đủ header để gán một cá nhân. Ghi “WCF/custom; tác giả cá nhân chưa xác minh”.

`BulletHell` và `Random Event Patch` đã trộn/sửa nhiều. Patch có nhãn “Galv Invader”, nhưng nhãn đó chưa đủ để xác định đúng bản gốc, ngôn ngữ/engine gốc hay license. Cần tìm lại nguồn đã dùng trước khi kết luận attribution.

## Thông tin còn cần lưu vào hồ sơ phát hành

- Bằng chứng license KUL/Ultra Lighting của project.
- Nguồn gốc và credit đầy đủ của hai script Invader đã merge.
- License/script page gốc của các mục hiện chỉ có header.
- Quyền phân phối source chỉnh sửa đối với Galv, Dekita, Khas và Zeus81 nếu công bố repository chứa source. Yêu cầu này tách biệt với quyền phát hành game phi thương mại.

Lượt này chỉ tổng hợp attribution và sửa lỗi cục bộ; không tự đổi license, không xóa header và không xác nhận rằng repository hiện đã đủ quyền phân phối mọi source.
